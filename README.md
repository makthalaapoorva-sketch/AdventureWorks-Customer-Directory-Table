## 📌 Project Overview

While executive summaries provide top-level metrics, operational teams frequently require granular, row-level data to verify transaction totals, export customer contact details, and review specific demographics. 

This repository highlights the **Page 3 Detail View**, engineered to balance high information density with clean, modern executive styling.

### Primary Objectives:
* **Auditability:** Provide a complete record of individual customer metrics matching top-level financial reports.
* **Filterability:** Allow dynamic slicing across occupations, education levels, and regions without compromising rendering speed.
* **Readability:** Utilize alternating row colors and distinct column headers to prevent visual fatigue during long analysis sessions.

---

## 🏗️ Table Architecture & Fields

The detail table aggregates fields from dimensional (`DimCustomer`) and transactional (`FactInternetSales`) schema tables:

| Column Name | Source Table | Data Type | Purpose / Description |
| :--- | :--- | :--- | :--- |
| **`CustomerKey`** | `DimCustomer` | Integer | Unique primary key identifying the customer. |
| **`FirstName`** | `DimCustomer` | Text | Customer's first name. |
| **`LastName`** | `DimCustomer` | Text | Customer's last name. |
| **`EmailAddress`** | `DimCustomer` | Text | Contact email for marketing & support follow-ups. |
| **`Gender`** | `DimCustomer` | Text | Gender demographic identifier (`M` / `F`). |
| **`EnglishOccupation`** | `DimCustomer` | Text | Professional classification (`Professional`, `Management`, `Skilled Manual`, etc.). |
| **`MiddleName`** | `DimCustomer` | Text | Customer middle initial/name (or NULL). |
| **`Phone`** | `DimCustomer` | Text | Primary contact telephone number. |
| **`SalesAmount`** | `FactInternetSales` | Currency ($) | Sum of total internet sales generated by the customer. |

## 🎨 Design & Formatting Standards

* **Typography & Palette:** Custom dark purple container background framed with crisp white row backgrounds for high text legibility.
* **Currency Standard:** All financial aggregates in the `SalesAmount` column are formatted explicitly as Currency (`$#,##0.00`) via Column Tools.
* **Row Layout:** Configured with minimal padding and alternating row shading to optimize line-by-line scannability across large record lists.
* **Totals Row:** Standard bottom summary row active to confirm grand total revenue ($180,588.31) matches executive summary cards.

---

## 💡 Key Operational Use Cases

1. **VIP & Top Spender Identification:** Sort by `Sum of SalesAmount` descending to instantly isolate high-yield accounts for loyalty outreach.
2. **Targeted Demographics Filtering:** Combine table rows with occupation or region slicers to pull specific campaign contact lists.
3. **Data Verification:** Serves as the underlying source-of-truth verification page when reconciling KPI summary cards from executive overview pages.
